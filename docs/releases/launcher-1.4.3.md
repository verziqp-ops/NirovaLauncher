# NIROVA Launcher 1.4.3

- Вернулся обычный читаемый шрифт по умолчанию. В настройках появился сохраняемый переключатель «Пиксельный текст», который действует сразу.
- В миниатюрах тёмной, светлой и системной темы убрана сетка; ступенчатые рамки интерфейса сохранены.
- Раздел «Версии» и создание новых экземпляров ориентированы на NIROVA Rust. Запуск старых Java-экземпляров отключён, их файлы не удаляются.
- Гостевая подготовка ресурсов из собственных файлов больше не заменяется входом Microsoft после проверки аккаунтов. Проверка права на скачивание файлов Mojang сохранена.
- Добавлен ручной импорт готового архива игры NIROVA Rust для текущей платформы. Импортированные и ранее установленные версии видны даже без опубликованных релизов или при ошибке сети. Импорт доступен гостю.
- Автоматическая установка по-прежнему проверяет подпись релиза. Ручной импорт предназначен для самостоятельно выбранных архивов из доверенного источника, например артефактов сборки этого репозитория.
- Исправлена сборка Rust-игры на macOS (Bash 3) и проверка Linux-архива сервера, падавшая из-за преждевременного закрытия канала.

Rust-клиент соответствует Minecraft 26.3; это не каталог произвольных Java-версий. Для запуска требуются отдельно подготовленные ресурсы из собственных файлов Minecraft. Пока подписанный релиз игры не опубликован, кнопки скачивания Rust-релизов не появятся: используйте импорт архива.
