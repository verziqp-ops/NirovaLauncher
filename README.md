# NIVRORA Launcher

**NIVRORA Launcher** — неофициальный лаунчер Minecraft Java Edition на Rust. Проект развивает собственный интерфейс, управление версиями и экземплярами, профили игроков и инструменты производительности.

## Интерфейс и языки

- Основной язык при первом запуске — русский.
- Также доступны украинский, английский, немецкий, французский, испанский, польский, португальский, японский, турецкий и китайский.
- Язык переключается в Настройки → Язык.
- Визуальная система NIVRORA: графитовый фон, сине-серые оттенки, молочно-голубые действия и сдержанный розовый акцент.
- Собственная навигация: Главная, Версии, Экземпляры, Миры и Настройки.

## Профили

- **Гостевой профиль** — локальное имя без входа в Microsoft. Он позволяет пользоваться интерфейсом и переключать локальный профиль; для запуска Minecraft требуется подтверждённое право на игру и подготовленные игровые файлы.
- **Лицензионный аккаунт** — вход через Microsoft OAuth с проверкой Minecraft: Java Edition. Секреты хранятся в системном хранилище учётных данных.

Лаунчер не подделывает токены и не отключает проверку владения игрой. Для загрузки игровых файлов с сервисов Mojang требуется аккаунт с правом владения Minecraft: Java Edition.

## Игровой движок и многопоточность

Текущая симуляция мира выполняет зависимые игровые фазы последовательно. Блоковые тики, редстоун, сущности, мобов и межсистемные события нельзя безопасно разнести по потокам без модели владения состоянием и детерминированной синхронизации.

Архитектурный план находится в [docs/region-threading-ru.md](docs/region-threading-ru.md). Целевой подход:

1. Зафиксировать эталонное ванильное поведение и воспроизводимые трассы событий.
2. Назначить каждому региону единственного владельца изменяемого состояния на время тика.
3. Оставить взаимодействия внутри региона последовательными и детерминированными.
4. Передавать события через очереди сообщений на границах регионов, не изменяя соседний регион напрямую.
5. Включать параллельное выполнение только после тестов редстоуна, мобов, поршней, воронок, жидкостей, чанков, порталов и сохранений.
6. Сохранять однопоточный планировщик как эталон и безопасный резервный режим.

**Важно:** региональная многопоточность пока является планом разработки, а не готовой функцией. До завершения дифференциальных тестов она не включается в игровую симуляцию.

## Сборка и релизы

GitHub Actions собирает лаунчер для Windows, Linux и macOS. Для Windows готовится NIVRORA-Setup.exe, для macOS — NIVRORA DMG и ZIP с приложением, для Linux — архив с бинарным файлом. Артефакты и проверенные релизы публикуются в [Releases](https://github.com/verziqp-ops/NirovaLauncher/releases).

## Лицензии и сторонние компоненты

NIVRORA — независимый неофициальный проект, не связанный с Mojang или Microsoft. Торговые марки Minecraft, Mojang и Microsoft принадлежат их владельцам. Лицензии исходных и сторонних компонентов сохраняются в соответствующих файлах проекта.
