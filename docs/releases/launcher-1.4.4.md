# NIROVA Launcher 1.4.4

Rust-игра 26.3 входит в полный установщик лаунчера. Во вкладке «Версии» выберите папку установки и нажмите «Установить и играть». Ручное скачивание и импорт игрового ZIP больше не требуются. Первый запуск автоматически готовит ресурсы из найденных собственных файлов Minecraft; подтверждённый Microsoft-аккаунт может загрузить необходимые файлы из Mojang. Гость без нужных файлов должен указать собственную установку Minecraft 26.3.

- Нативный пакет доступен в каталоге даже без подключения к GitHub.
- Папка Rust-версий сохраняется между запусками; миры и существующие данные не переносятся и не удаляются.
- Изменённый пакет отклоняется по контрольному SHA-256, закреплённому в установленном лаунчере.
- Игровой процесс работает на Rust. Java/JDK используется только инструментами подготовки ресурсов.
- В расширенных настройках сохранён ручной импорт для локальных тестовых сборок.
- Установщики Windows, приложение macOS и Linux-архив содержат нативный runtime. При будущих подписанных обновлениях лаунчера он обновляется вместе с приложением.

Подготовленный Windows signing pipeline подписывает также вложенные native EXE перед упаковкой; после упаковки Defender и Authenticode проверяют все четыре EXE. Пока доверенный сертификат/профиль сервиса не выдан, preview остаются неподписанными. Сообщения Chrome/SmartScreen о неизвестном издателе этим изменением не объявляются устранёнными.
